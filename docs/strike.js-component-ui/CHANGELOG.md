# Changelog

## 0.2.0

- Table data API: getRowId, getRowClassName, column class/headerClass/width/align, sticky header token, padTop/padBottom spacers.
- Peer strike-fw >= 0.2.1 (Check indeterminate + transition entry).
- Tooltip: Portal + fixed placement from trigger size; wrapper is max-content so flex parents do not stretch it.
- Snackbar: full-bleed flex strip for start/center/end (no left:50% transform).
- SnackbarStack / SnackbarHost / snackbar.show: stackable toasts with max, gap, and `transition` (strike-fw/transition presets + FLIP).

## 0.1.0

- data/media/steppers: Table, ImageList, Video, Audio, Stepper.
- overlays/chrome: Overlay, Drawer, Menu, MenuBar, Snackbar, Pagination, Navigation.
- structure: Portal, Card, Container, Grid, List, Accordion, AppBar, Breadcrumbs, Tabs, Tooltip.
- foundations: Box, Paper, Link, Icon, Divider, Avatar, Badge, Chip, Alert, Progress, Skeleton.
